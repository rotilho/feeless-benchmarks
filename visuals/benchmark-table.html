What was tested

The 500-account benchmark ran ten times, with 50,000 transactions per run. The serial benchmark ran once, with 1,000 transactions from one account. Every transaction completed without errors.

End-to-end benchmark

Timing covers the full client path on the local test network, from sending a transaction until the node reports it complete. It includes communication with the node and node processing, not only consensus time.

Host sensitivity

All runners exposed four logical processors. The paired spread is consistent with Atto benefiting more from CPU performance and putting less pressure on storage, while Nano and RSNano appear more sensitive to disk performance. GitHub did not record a disk benchmark, so this is an observed pattern, not a controlled causal result. View the source run.
